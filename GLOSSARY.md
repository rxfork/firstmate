# Firstmate terminology

## Language

**Vessel**:
A portable Firstmate working environment containing its operational state and working repositories.
_Avoid_: Ship, capsule.

**Anchor**:
The physical location occupied by a vessel at a harbor.

**Harbor**:
A host where a vessel can reside.
_Avoid_: Port.

**Ship task**:
An implementation task assigned to a crewmate, not the portable working environment.
